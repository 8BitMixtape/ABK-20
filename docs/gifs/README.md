# ABK-20 Sketch Visual Previews (`docs/gifs/`)

This directory contains animated GIF recordings of the 5x4 NeoPixel matrix / bi-color LED animations corresponding to each firmware sketch:

- `acid_AKB20.gif`: Acid 303 sequencer & VU meter visualization
- `interface_test.gif`: Hardware diagnostic and potentiometer testing animation
- `test_bicolor_led.gif`: Ultrasonic bi-color LED color blending and strobing

These are displayed on the [Web Flasher Index](../index.html).
